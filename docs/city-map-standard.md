# 城市地图展示规范

所有城市详情页使用同一套双层地图组件，避免远郊节点压缩城区节点的可读空间。

## 主图：核心区局部放大

- 根据节点经纬度自动识别密集核心区，不按节点名称硬编码。
- 主图只放大核心区，但不得修改节点的真实相对方位。
- 节点可点击，并与下方节点卡和详情页保持同一 ID。
- 主图必须显示根据当前经纬度范围计算的比例尺。

## 小图：城市全域概览

- 同时展示城市全部节点，包括远郊景区、遗址和交通门户。
- 用范围框标明主图覆盖区域。
- 远郊节点必须可点击并显示名称。
- 小图使用独立比例尺；与核心区的跨度仅在前端动态计算，不写回数据库。

## 数据原则

- 地图只读取 `location.latitude`、`location.longitude` 和 `coordinate_system`。
- 坐标系统统一使用 GCJ-02。
- 不为改善视觉排版而移动节点坐标。
- 不在 JSON 中保存景点间固定距离；驾车、步行和公交数据继续由高德 API 动态计算。
- 当城市节点不足或不存在明显远郊点时，组件保留同一视觉格式，但全域图可显示“全部节点”。
